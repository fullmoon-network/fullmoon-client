# Fullmoon Client v0.4.0 — 베타 서버 대응

풀문 클라이언트의 **정식 릴리즈**예요. 이번 업데이트는 기존 운영 서버에서
사용하던 클라이언트에 **1.0.2 베타 서버 지원**을 추가한 것이에요.
베타인 것은 테스트 서버의 콘텐츠이며, 이 클라이언트는 프리릴리즈가 아니에요.

## 새 기능

- 풀문 네트워크의 **1.0.2 베타 서버**와 네이티브 메뉴로 연동해요.
  시즌패스, 미션 추적 HUD, 스킨 옷장, 운영 로비로 돌아가기 기능이 있어요.
- 베타 서버의 GUI·스킨 리소스팩을 **기본 내장**했어요.
  외부 팩 서버에 연결하지 않아도 기본 외형을 사용할 수 있어요.
- 리소스팩을 갱신할 때 파일 해시를 검증하고, 중단되거나 실패해도
  이전 파일과 설정을 보존해요.
- 런처의 원자적 파일 저장, 중복 실행 방지, Windows 설치·Linux 실행 검증을 개선했어요.

## 다운로드

| 파일 | 용도 |
| --- | --- |
| `Fullmoon_1.3.0_x64-setup.exe` | Windows x64 설치 파일 |
| `Fullmoon-1.3.0-1.x86_64.rpm` | Fedora 등 RPM 계열 |
| `Fullmoon_1.3.0_amd64.deb` | Debian·Ubuntu 계열 |
| `fullmoon-client-3.3.0.jar` | Fabric 모드만 수동 설치할 때 |
| `SHA256SUMS` | 다운로드 파일의 무결성 확인 |

**런처 1.3.0 · Fabric 모드 3.3.0 · Minecraft 26.1.2**

Windows 설치 프로그램과 Linux 패키지는 GitHub Actions에서 빌드하고
설치·기동 스모크를 확인한 뒤 게시해요. Fabric 모드는 런처에 포함되어 있으므로
별도 설치할 필요가 없어요.

## 알아두세요

- 테스트 서버의 재화와 아이템은 운영 서버와 섞이지 않아요.
- 테스트 서버 콘텐츠는 베타로 운영돼서 변경되거나 초기화될 수 있어요.
- 스모크 테스트는 자동 검증이에요. 실제 모든 Windows 장치나 Linux 배포판에서
  완전히 동일하게 동작함을 보장하지는 않아요.
- 로그인 시 Microsoft 계정과 Minecraft 정품 라이선스가 필요할 수 있어요.
